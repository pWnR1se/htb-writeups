# Bug Bounty

**Disclosed findings only.** Nothing is published here unless:

1. the report is **resolved / fixed**, and
2. the program has **explicitly authorized public disclosure**.

Undisclosed vulnerabilities, program-internal details, and anything under
embargo stay out of this repository. When in doubt, it does not go here.

This folder is mainly for **methodology** and **sanitized** case studies —
technique and process, with target-identifying details removed.
